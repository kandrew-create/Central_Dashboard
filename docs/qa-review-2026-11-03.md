# Central Dashboard QA review — 3 November 2026

## Verdict and scope

**All 351 collected automated test cases passed at least once across the appropriate Windows, Linux and desktop environments. No confirmed functional defect remains from this run.** This is automated regression evidence for the current 0.6.2 repository, not approval of every deployment scenario or a guarantee of production readiness.

Scope includes the Central Server managers, ingestion and worker, shared upload/setup interfaces, Collector integration, deployment configuration and installer safeguards. Customer portal/reporting, analytics, Grafana, OIDC and notifications remain outside the implemented feature scope described by this repository. Separately running applications were not treated as part of this checkout.

The working tree was clean before QA. No application behavior, installed settings, source registrations, operational databases, queues or credentials were changed. Tests used disposable clusters/profiles and synthetic records. Live checks read readiness and saved AI configuration; they did not enable AI or invoke a model. Existing Windows/Linux installations and named volumes were preserved.

## Findings and retests

1. **Test-container limitations, resolved by supported-environment retest.** `tests/test_wsl_installer.py::PackageTests::test_payload_is_reproducible_and_excludes_operational_files` fails inside the runtime test image because required top-level packaging inputs are absent. Two Linux installer preflight tests hit the normal-user requirement because the test target runs as root. All three passed from the full checkout as the normal WSL user. The existing test image therefore cannot be described as an entirely green full-suite runner without qualifying its environment. No installer guard was weakened.
2. **Transient Windows display skip, resolved.** The PostgreSQL 18 run skipped `ManagerWindowTests::test_delete_in_network_mode_refreshes_list_and_preserves_success_message` when desktop initialization was unavailable. An isolated host rerun passed.
3. **Non-blocking dependency warning.** FastAPI/Starlette TestClient emits an httpx deprecation warning. No dependency was changed during QA. Future dependency maintenance should address it with a compatible, tested update.
4. **Installed Windows package unavailable.** `C:/Program Files/Linker/Central Server/central-server.exe` is absent. This run makes no new claim about the published X3 binaries or installer execution.
